# 故障排查

[English](../en/troubleshooting.md) · **简体中文**

## 安装与启动

| 问题 | 先检查 | 处理 |
|---|---|---|
| "Loomscreen.app 已损坏 / 无法打开" | ad-hoc 签名构建上的 Gatekeeper 隔离标记——不是真的损坏 | 执行一次 `xattr -dr com.apple.quarantine /Applications/Loomscreen.app`，然后重新打开 |
| 菜单栏图标不见了 | 应用还在运行吗（活动监视器）？菜单栏是不是太挤？ | 从 `/Applications` 重新启动；检查登录项限制 |
| 完全启动不了 | 是否为 Apple Silicon 上的 macOS 14.6+？ | Intel Mac 与更老的 macOS 不受支持 |

## 渲染

| 问题 | 先检查 | 处理 |
|---|---|---|
| 什么都没渲染 / 壁纸全黑 | **设置 → 显示器** 里指定来源了吗？总开关开着吗？ | 指定来源；把菜单栏总开关关掉再打开 |
| 壁纸老是自己暂停 | 暂停规则：全屏、遮挡 ≥85%、电池、低电量模式、按 App 例外 | 这是设计行为——在 **设置 → 性能** 里放宽规则，或加一条**从不暂停**的 App 例外 |
| 第二台显示器一直空白 | 来源的文件权限覆盖到那台显示器的配置了吗？ | 重新打开该显示器的详情面板，显式重新指定来源 |
| 大视频卡顿 | 4K 以上的源？帧率上限太高？叠加层开着？ | 降低帧率上限与内存预载预算；关掉粒子/天气叠加层来定位 |
| 桌面点击像是被挡住了（场景） | 场景的**点击交互**会捕获鼠标点击 | 关掉那台显示器的点击交互并重新加载 |

## 播放列表与计划

| 问题 | 先检查 | 处理 |
|---|---|---|
| 计划不切换 | 时段重叠？书签还有效吗？那个时间点应用是不是被暂停了？ | 修掉高亮出来的冲突；重新保存该时段；注意锁屏或休眠期间自动化是停的，唤醒后只对齐**一次**——错过的时段不会补触发 |
| 播放列表间隔不生效 | 至少有两个有效条目吗？播放列表模式开了吗？ | 重设间隔并重新保存；休眠/解锁后倒计时是重新开始，而不是接着走 |

## 导入

| 问题 | 先检查 | 处理 |
|---|---|---|
| 网页文件夹加载不了 | 能从文件夹里推断出入口文件吗？ | 直接指向那个 `.html` 文件 |
| 场景导入立刻失败（Pro） | 文件夹里有 `project.json` 吗？ | 导入工程文件夹本身，不要导入它的父目录；需要 Windows 可执行文件的工程会按设计跳过 |

## 创意工坊（Pro）

| 问题 | 先检查 | 处理 |
|---|---|---|
| 下载失败 | SteamCMD 状态、Steam 登录 | 打开创意工坊侧栏里的 **Steam 连接**页——它会诊断 SteamCMD、账号和引擎资源，并能自动配置 |
| **安装 SteamCMD…** 失败 | 失败信息会指出是哪一步：拉清单、下载、校验和，还是签名 | 校验和或签名被拒说明下载到的不是 Valve 的东西——重试，别想办法绕过。你原来的配置会被回滚，不会被留在半坏状态。如果一直失败，就自己装 SteamCMD 再用**自动查找** |
| 你自己指定的 SteamCMD 突然不能用了 | 它是**每次运行**都重新验证的，不只是你选它的那一次——某次升级改了签名就会被拒 | 用**选择 SteamCMD…** 重新指定，或者改用托管安装 |
| 浏览页空白 | 填了 Steam Web API key 吗？ | 在 **设置 → 创意工坊** 里加一个（在 steamcommunity.com/dev/apikey 免费申请） |
| 某张壁纸的预设列表是空的 | 列出预设需要 Steam Web API key，下载预设需要 SteamCMD | 先把 key 填上；如果显示"这张壁纸还没有人发布预设"，那就是字面意思 |

## 还是不行？

1. 在 **设置 → 性能** 里把相关的暂停规则切换一下再试。
2. 动手折腾之前，先从 **设置 → 备份与恢复** 导出配置。
3. **设置 → 关于 → 报告问题…** 会自动填好诊断信息和最近的日志行——请附上复现步骤并提交
   [issue](https://github.com/Paradox07127/macos-wallpaperengine/issues)。
