# 故障排查

[English](../en/troubleshooting.md) · **简体中文**

## 安装与启动

| 问题 | 先检查 | 处理 |
|---|---|---|
| "Loomscreen.app 已损坏 / 无法打开" | Gatekeeper 可能拦截未公证构建，但这条提示不能单独确定原因 | 校验 DMG 后按[安装说明](install.md)使用对应 Lite/Pro 命令；仍失败则收集启动错误 |
| 菜单栏图标不见了 | 应用还在运行吗（活动监视器）？菜单栏是不是太挤？ | 从 `/Applications` 重新启动；检查登录项限制 |
| 完全启动不了 | 是否 macOS 14.6+？Pro 另需 Apple Silicon | Lite 带一个未经测试的 Intel 切片；Pro 仅支持 Apple Silicon |

## 渲染

| 问题 | 先检查 | 处理 |
|---|---|---|
| 什么都没渲染 / 壁纸全黑 | **设置 → 显示器** 里指定来源了吗？总开关开着吗？ | 指定来源；把菜单栏总开关关掉再打开 |
| 壁纸老是自己暂停 | 暂停规则：全屏、遮挡 ≥85%、电池、低电量模式、按 App 例外 | 菜单栏和该屏详情页会写明是哪条规则压住了它——可选规则可在**设置 → 性能**调整或添加**从不暂停**例外，安全暂停不可覆盖 |
| 第二台显示器一直空白 | 来源的文件权限覆盖到那台显示器的配置了吗？ | 重新打开该显示器的详情面板，显式重新指定来源 |
| 大视频卡顿 | 源分辨率/编码、叠加层、资源压力 | 尝试较低分辨率来源，调整帧率目标，关闭叠加层定位；预载预算是在内存与磁盘/解码工作之间取舍 |
| 桌面点击像是被挡住了（场景） | 场景的**点击交互**会捕获鼠标点击 | 关掉那台显示器的点击交互并重新加载 |

## 播放列表与计划

| 问题 | 先检查 | 处理 |
|---|---|---|
| 计划不切换 | 时段重叠？书签还有效吗？那个时间点应用是不是被暂停了？ | 修掉高亮出来的冲突；重新保存该时段；注意锁屏或休眠期间自动化是停的，唤醒后只对齐**一次**——错过的时段不会补触发 |
| 播放列表间隔不生效 | 至少有两个有效条目吗？播放列表模式开了吗？ | 重设间隔并重新保存；休眠/解锁后倒计时是重新开始，而不是接着走 |

## 导入

| 问题 | 先检查 | 处理 |
|---|---|---|
| 网页文件夹加载不了 | 能从文件夹里推断出入口文件吗？ | 直接指向那个 `.html` 文件 |
| 场景导入立刻失败（Pro） | 项目须有 `project.json`，资源库须含项目子目录 | 选择项目或支持的库文件夹，查看具体错误；不支持 Windows 可执行程序壁纸 |

## 创意工坊（Pro）

| 问题 | 先检查 | 处理 |
|---|---|---|
| 下载失败 | SteamCMD 状态、Steam 登录 | 打开 **设置 → 创意工坊** —— **Steam 连接**那一节会诊断 Steam 库、SteamCMD 和你的账号，并能自动配置。展开该节里的**诊断**可以看逐项探针 |
| **安装 SteamCMD…** 失败 | 错误指出 manifest、下载、校验和或签名验证失败 | 重试；不匹配可能来自下载不完整或信任验证失败，不能仅据此判定原因。不要绕过验证，必要时选已有可信安装 |
| 你自己指定的 SteamCMD 突然不能用了 | 它是**每次运行**都重新验证的，不只是你选它的那一次——某次升级改了签名就会被拒 | 用**选择 SteamCMD…** 重新指定，或者改用托管安装 |
| 浏览页空白 | 筛选、网络、API 功能所需 key 的状态 | 清掉过严筛选后重试；公共浏览可不用 key，作者/预设/API 查询可能需要。预设默认不进入通用浏览网格 |
| 某张壁纸的预设列表是空的 | 列出预设需要 Steam Web API key，下载预设需要 SteamCMD | 先把 key 填上；如果显示"这张壁纸还没有人发布预设"，那就是字面意思 |

## 叠加层、备份与更新

| 问题 | 检查与下一步 |
|---|---|
| Apple Music 进度或控制不可用 | 在 macOS 隐私与安全性 → 自动化中允许 Loomscreen 控制 Music；没有可用播放位置的曲目不能提供同步进度 |
| 歌词缺失或不滚动 | 启用歌词，检查网络与曲目匹配；并非每首歌都有 LRCLIB 时间歌词 |
| 天气组件没有当前天气 | 选择系统/手动位置，检查天气设置与网络 |
| 导入备份里有场景，Lite 却没有壁纸 | Lite 保留配置数据但不能运行 Pro 场景；换成视频/网页来源，或在 Pro 中打开配置 |
| 系统壁纸不可用 | 需要 macOS 26+ 和兼容 provider。状态显示暂停时使用应用原有视频路径；添加视频后仍需在 macOS 壁纸设置选择 |
| 关闭更新窗口后标记还在 | Sparkle 会话保留时可能继续显示标记；通过更新窗口操作，不代表重复下载 |
| 更新下载/校验失败 | 网络恢复后重试，不绕过签名验证；Releases 提供对应版本的手动 DMG 与校验和 |

## 还是不行？

1. 在 **设置 → 性能** 里把相关的暂停规则切换一下再试。
2. 动手折腾之前，先从 **设置 → 备份与恢复** 导出配置。
3. **设置 → 关于 → 报告问题…** 会自动填好诊断信息和最近的日志行——请附上复现步骤并提交
   [issue](https://github.com/Paradox07127/macos-wallpaperengine/issues)。
