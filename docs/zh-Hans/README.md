# Loomscreen 文档

[English](../README.md) · **简体中文**

Loomscreen 是一个以菜单栏为核心的 macOS 动态壁纸平台：用 Metal 原生渲染
Wallpaper Engine 场景（Pro），另支持视频、网页与 Apple Aerials 壁纸，可按显示器
分别配置，并带播放列表与自动化。
