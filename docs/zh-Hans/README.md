# Loomscreen 文档

[English](../README.md) · **简体中文**

Loomscreen 是免费开源的 macOS 动态壁纸应用，可视化工作台连接显示器全景、
壁纸架、统一壁纸库与叠加层画布。两个版本均支持视频、网页和 Apple 航拍，
Pro 另有 Metal 原生渲染的 Wallpaper Engine 场景与创意工坊；日常控制留在菜单栏。
