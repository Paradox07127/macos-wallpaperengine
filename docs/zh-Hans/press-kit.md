# Loomscreen 宣传文案

[English](../en/press-kit.md) · **简体中文**

供项目主页、社交公告与演示复用，描述当前工作台。版本发布说明仍应只描述该版本的改动，
遵守[发版说明](releasing.md)的格式。

## 主宣传语

**让桌面动起来，也让它成为你的空间。**

原生 macOS 动态壁纸，用全景工作台管理每台显示器，在统一画布上排列小组件、音乐与天气。

## 一句话介绍

Loomscreen 是免费开源的 macOS 动态壁纸应用，把显示器、壁纸和桌面叠加层放进同一个可视化工作台。

## 短介绍

看见每台显示器，把壁纸拖到合适的位置，在一块画布上排列小组件、时钟与音乐。
Loomscreen 支持视频、网页和 Apple 航拍，Pro 另有独立的 Wallpaper Engine Metal 场景渲染器
与 Steam 创意工坊。保存整屏方案、自动轮换壁纸，日常控制留在菜单栏。
两个版本均免费、MIT 开源，无需 Loomscreen 账号，不收集使用遥测。

## 新界面公告

**你的桌面，有了新的工作台。**

新版 Loomscreen 从显示器出发：全景、壁纸架与完整壁纸库连续展开；显示器编辑器把播放控制
和统一叠加层画布带到正在布置的桌面旁。选壁纸、摆组件，再把整套配置存成方案。

## 功能配图短句

- **每台显示器，一眼看清。** 看见每张壁纸放在哪里。
- **从壁纸库，到你的桌面。** 拖到显示器上，或按名称应用。
- **一块画布，安排所有图层。** 小组件、时钟与音乐一起摆放。
- **桌面跟着一天的节奏变化。** 播放列表、每日计划与壁纸库随机轮换。
- **在 Mac 上运行 Wallpaper Engine 场景。** Pro 用 Metal 原生渲染兼容场景。
- **你的文件，你的配置。** 无需 Loomscreen 账号，不收集使用遥测。

## 宣传边界

| 主题 | 准确表述 |
|---|---|
| 版本 | Lite 与 Pro 都免费开源；Pro 增加 WPE/创意工坊栈及相关能力 |
| WPE | 独立实现，兼容程度随项目而异，不承诺与 Windows 全面一致 |
| 创意工坊 | 使用用户自己的 Steam 账号与授权下载，不捆绑内容、不绕过授权 |
| 隐私 | 无 Loomscreen 账号或使用遥测；可选在线功能会访问各自的服务 |
| 性能 | 有节能规则和可调帧率上限；效率比较需要实测证据 |
| Intel | Lite 提供尚未在 Intel 真机验证的切片；Pro 要求 Apple Silicon |
| 系统壁纸 | macOS 26+、仅视频、受 provider 兼容性限制；不包含应用场景、网页或叠加层 |
