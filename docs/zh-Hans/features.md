## 应用界面

- **菜单栏**：添加壁纸、总开关、逐屏播放和音量、播放列表切换、CPU/GPU/内存/热压力、更新、设置与退出。
- **管理窗口**：全景、壁纸库、**方案**（保存的整屏配置）、系统壁纸（macOS 26+）、创意工坊（Pro）和设置。
- **显示器编辑器**：壁纸与叠加层两个标签；叠加层使用统一画布、图层列表、对象检查器和添加面板，放置小组件、时钟与音乐；效果层提供粒子与天气联动。开启小组件交互时，只在可见小组件区域接收点击，空白桌面仍可穿透。
- **引导**：浮动欢迎导览与当前页指引高亮实际控件。
- **语言**：英语、简体中文、繁体中文、日语、西班牙语。

## 壁纸类型

### 视频——两个版本

- 支持 `mp4`、`m4v`、`mov`、`avi`，实际可播放性取决于 AVFoundation 可用的编解码器。
- 填充、适合、拉伸；播放速度、静音/音量与视频效果。
- 自动、sRGB、Display P3、Rec. 2020 HDR、强制 SDR 色彩模式。
- 逐屏独立播放，或让视频跨屏铺展。
- 每屏可配置内存预载预算。
- 帧率上限可输入 1 到该屏当前刷新率之间的整数，或选**最高**；支持的预设包含 15/24/30/45/60/120。控件显示配置的上限，不是实测 FPS；视频还受源帧率限制。旧版帧率配置在读取时迁移。

### 网页——两个版本

URL、HTML 文件、本地文件夹和内联 HTML 通过 WKWebView 运行。可设置 JavaScript、
鼠标交互、跟踪器拦截、自定义 CSS、静音/音量、刷新间隔、缩放/平移/旋转和物理像素布局。
创意工坊网页导入使用临时存储与网络隔离；用户自建网页来源可按配置访问网络。

### Apple 航拍——两个版本

浏览、搜索并应用 macOS 已下载的航拍视频。航拍壁纸走视频播放路径，Loomscreen 不负责下载 Apple 目录。

### Wallpaper Engine 场景——Pro

本地项目文件夹与已下载的创意工坊内容就地读取。原生 Metal 渲染器支持分层场景、粒子、
木偶变形、文字、SceneScript、音频响应和光标效果。场景 GLSL 转译为 Metal，不是另一种壁纸类型。

兼容程度随项目和功能而异。导入预检与运行时错误会说明不支持的内容或缺失资源；
这是独立实现，不保证每个 Windows 项目都呈现相同效果。不支持 Windows 可执行程序壁纸。

**场景预设**为基础壁纸保存一组命名参数。场景默认值、预设、逐屏修改分层保存。
预设行提供选择、保存、重命名和删除；创意工坊壁纸详情页在有 Steam Web API key 时列出社区预设，无 key 时提供其 Steam 页面链接。

预设还可携带 Wallpaper Engine 的色彩校正与音量。启用且非中性时，色彩校正执行全帧处理；
曲线沿用 Loomscreen 视频控件，不宣称与 WPE 完全一致。预设音量乘以显示器音量。
这些引擎设置与项目中恰好同名的属性分开保存。

**跨所有显示器**同样适用于场景，把一个场景铺展到多台显示器。有显示器加入或离开时，
场景会在剩下的显示器上重新布局。其中一台换成视频或网页后，它就退出跨屏。
应用方案不会让显示器加入跨屏。适配、静音和音量的修改也会同步到已断开的跨屏显示器。

## 换壁纸动画——两个版本

**设置 → 通用 → 壁纸**里有两项设置。

- **换壁纸动画**在显示器切换壁纸时播放。可选无、淡入淡出、流星、墨晕、漏光、极光幕、
  织光、涟漪、焦外、碎晶、百叶、星尘和随机，默认是淡入淡出。
- 涟漪、焦外、碎晶、百叶、星尘会把旧壁纸的一帧扭曲成新壁纸的一帧。视频和场景能提供这一帧；
  网页壁纸和跨屏场景不能，这类切换改用淡入淡出。
- 自动轮换时播放同一种动画，速度放慢。
- **开场动画**在启动恢复壁纸时，每台显示器播放一次。可选关闭、一线织屏、画框展开、破晓和随机，
  默认是一线织屏。
- 一次操作切换多台显示器时，各屏的动画同时开始。
- 开启“减弱动态效果”或低电量模式时，换壁纸动画改为短暂的淡入淡出，开场动画改为短暂的淡入。
- **在截屏与共享中显示壁纸**同样作用于动画窗口。关闭后，截屏、录屏和共享里也看不到动画。

## 书签、方案与自动化

- **书签**：用黄色书签标记常用的壁纸，在壁纸库选**书签**筛选即可只看这些。
- **喜欢**（Pro）：在创意工坊条目上点粉色心形即可喜欢，以便稍后下载；打开创意工坊筛选栏里的**已喜欢**开关，即可列出所有喜欢过的条目。
- **方案**：包含壁纸、叠加层、播放、效果、播放列表、计划的整屏配置。确认后替换目标显示器的配置，位置适配目标显示器。
- **壁纸自动切换**：从显示器顶栏打开的面板，有播放列表、每日计划、壁纸库随机三种模式。
- **播放列表**：视频、网页、场景（Pro），拖拽排序、随机播放，每 1、5、15、30、60 或 120 分钟轮换，或手动切换。
- **计划**：时段、冲突检查、主壁纸兜底；锁屏/休眠时暂停，唤醒后对齐一次。
  时段排在**24 小时计划**圆盘上。拖动圆弧端点调整时间，双击空闲时段添加新时段。
  **未安排的时段**指定没有时段覆盖时用的壁纸。
- **壁纸库随机**：按设定间隔从整个壁纸库随机选壁纸。新导入的壁纸自动加入，不会连续播放同一张。
  **随机下一张壁纸**可立即换下一张。
- **已跳过的壁纸**：加载失败的壁纸会重试一次，再失败就跳过。面板列出每一张及原因
  （文件丢失、加载失败或加载超时），点**重新启用**即可恢复。
- 手动选壁纸、应用方案或应用创意工坊条目（Pro）后，轮播倒计时从头计算。离开期间（锁屏或显示器休眠），
  播放列表和壁纸库随机的倒计时冻结，回来后从剩余时间继续。
- 所在卷未挂载的壁纸本轮直接略过，不会被标为已跳过。
- **快捷键**：播放/暂停、下一张、上一张、静音、鼠标交互、全局可见性、重载、设置，共八个动作。
- **备份**：`.lwconfig` 保存逐屏配置、全局设置、书签与方案（Pro 另含创意工坊喜欢），不打包媒体文件、Steam 凭据或 API key。文件授权与机器相关，迁移后可能需要重新选择来源。Lite 无法播放备份里的 Pro 场景配置。

## 叠加层

叠加层逐屏配置，可搭配视频、网页或场景。粒子、监控与音乐层也能在没有 Loomscreen
活动壁纸会话时叠在 macOS 桌面上。显示器的**叠加层**编辑器在同一画布上展示小组件、时钟与音乐，
统一定位、选择和对象控制；粒子与天气联动通过效果层设置。见[工作台指南](workspace.md#排列叠加层)。

- **12 种粒子效果**：雪、雨、散景、萤火虫、尘埃、星星、落叶、樱花、薄雾、余烬、气泡、流星。支持适用效果的风向、“减少动态效果”与屏幕捕捉可见性设置。
- **天气联动**：Open-Meteo 天气驱动粒子选择与视频参数，位置可用系统定位或手动指定。
- **监控面板**：系统总览、CPU、内存、GPU、网络、磁盘、电源、进程、Agent 会话、ANE 内存、天气，共十一种组件。按类型提供小/中/大尺寸、拖拽排列、显示缩放、选项和布局导入/导出。可位于桌面或窗口上方。缺测与零读数有区别，曲线保留采样空隙；网络/磁盘累计为本次监控估算。
- **系统总览**：用一个中型或大型仪表整合 CPU、内存、GPU、网络吞吐、磁盘 I/O 和电源。大型增加历史曲线以及可选的温度、风扇读数，复用现有共享采样管线。
- **时钟**：独立的透明辉光管时钟，带金属底座与细玻璃管冒号。支持拖动位置、自由缩放、12/24 小时制、小时首位补零、透明度和冒号闪动；拥有独立的逐屏开关与图层，被遮挡时暂停，且不启动资源采样。
- **天气组件**：带天气/位置说明的天空场景，随昼夜变化，显示云、降水与风；独立于整屏天气联动设置。
- **Agent 会话**：读取本地 Claude Code 与 Codex 会话记录呈现状态；ANE 内存表示内存占用，不是神经引擎利用率。
- **音乐 / 正在播放**：独立的 Poster、Vinyl、Aurora 布局，封面取色、拖拽定位和可选歌词。Pro 开启音频响应后可使用含 Wave 在内的系统音频视觉效果。

曲目信息来自 Spotify/Apple Music 通知，必要时在启动阶段读取现有状态。
Apple Music 通知缺少播放位置，数据源活动时会通过 Apple Events 查询；授予自动化权限后，
进度与同步歌词可以跟随它。播放控制与跳转使用同一权限边界。
缺少可用播放位置或带时间歌词时会降级显示，不伪造同步时间。

封面与可选 LRCLIB 歌词通过 HTTPS 域名白名单、响应大小限制和缓存获取。
歌词默认关闭。预览使用已有封面缓存，不独立再发一次请求。

## 性能与显示器生命周期

播放状态机把用户的播放/暂停意图与系统策略分开。锁屏/休眠、严重内存压力、危急热状态
属于安全暂停；全屏、窗口遮挡、电池、低电量模式与逐应用规则可配置。
应用的**从不暂停**规则只覆盖可选策略。菜单栏与显示器状态说明暂停原因。

中度热压力会降低场景/网页帧率，也可能暂停视频。手动暂停保留静帧，经过驻留时间后
进入更深的资源休眠。Pro 另有场景自适应帧率与逐屏 render actor。逐屏配置持久保存。

手动暂停（在某台显示器上或用总开关）会一直保持。改属性、自动轮换、拔插显示器、重启应用后都仍是暂停。
点播放，或给这台显示器选一张壁纸，才会解除。配置备份不包含暂停状态。

视频和本地网页壁纸可以放在外接盘上。所在卷卸载后，显示器的配置保留；卷重新挂载后，
受影响的显示器自动重新加载。

## 创意工坊——Pro

- 分页浏览、缓存、成熟度/类型/分辨率/题材/Miscellaneous 筛选和标签翻译。成熟度默认只选 Everyone，与未登录的创意工坊网页一致；勾上 Questionable、Mature 两个标签即可显示这些分级。排序名、时间范围和搜索字段菜单（标题与描述 / 仅限标题 / 仅限描述）与 Steam 官方文案一致；默认排序为「最热门（1 周）」，可在创意工坊设置里更改。
- 公共浏览无需 key，直接读取网页自带的结果数据，因此无 key 的卡片也带作者名和页数。已保存的 key 被 Steam 拒绝时会自动切到公共路径，并给出可关闭的提示。
- 首批结果先于作者名称显示，切筛选时保留已有卡片。题材匹配任一所选项；Miscellaneous 所选项必须全部满足；标签/作者范围内仍保留其他筛选条件。
- 详情页显示发表/更新日期、评分数与评论数、依赖项、分组标签，以及该作品在 Steam 上的更新记录、评论和合集链接。
- **把预设当作壁纸显示**默认关闭；基础壁纸的详情页仍可查看预设。
- SteamCMD 支持托管安装、自动查找、手动选择；XPC 连接器验证并运行工具。
- 应用内登录支持 Steam Guard 与已缓存账号，逐账号保留会话，下载进入授权的 Steam 库。订阅同步让订阅项目出现在应用中。
- 下载导入前重新验证授权库内的目录；应用发起的删除与下载共用仓库修改协调。
- 可链接或安装 Wallpaper Engine 共享资源，并检查更新。
- 同一个创意工坊条目在壁纸库里只保留一份。从本地文件夹导入的场景如果同时有 Steam 下载版，
  启动时和下载完成后由 Steam 版取代它；用到本地副本的显示器、书签和方案都改指 Steam 版。本地文件夹仍留在磁盘上。
- 手动下载这类条目时，会先询问**替换壁纸库里的副本？**
- 导入文件夹时，如果其中的创意工坊条目已从其他文件夹加入壁纸库，该条目不会导入。文件夹导入会报告因此跳过的数量。

## 系统壁纸——两个版本，macOS 26+

**系统壁纸**库把支持的视频文件复制到 provider 的资源库，再通过 macOS 壁纸设置选择。
Loomscreen 关闭后，provider 仍可播放。这是独立的视频路径，不包含 Loomscreen 的场景、
网页和叠加窗口。页面报告 provider 兼容状态，在不支持的 macOS 构建上可暂停发布。
见[架构说明](architecture.md#系统壁纸-provider)。

## 更新与隐私

两个版本都使用 Sparkle，分别读取 HTTPS appcast 并验证更新包签名。
定时检查可弹出 Sparkle 更新窗口，菜单栏更新按钮和关于页也提供更新入口。
Sparkle 负责下载、安装与重启；通用设置控制自动检查。这不是仅访问 GitHub API 并提示链接的更新器。

无需 Loomscreen 账号，不收集使用遥测。可选在线功能会访问 Steam、天气、封面/歌词或
更新服务；远程网页壁纸也可访问自己的站点。新保存的 Steam API key 存入登录钥匙串；
旧版仅属主可读的文件在钥匙串写入并确认后迁移，迁移被拒时可能保留。
详见[安全策略](SECURITY.md)与[权限说明](install.md#系统权限提示)。
