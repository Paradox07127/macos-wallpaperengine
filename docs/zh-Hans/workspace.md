# 工作台指南

[English](../en/workspace.md) · **简体中文**

Loomscreen 在一个管理窗口里完成显示器配置与壁纸浏览。从菜单栏打开**管理**，
用完可以关窗；壁纸会继续运行，直到暂停或退出应用。

## 从显示器开始

**全景**按桌面排列展示显示器、壁纸封面与播放状态。点击显示器进入编辑器；
把支持的视频、网页文件夹或 Pro 场景项目拖到显示器上，即可为它指定内容。

全景、壁纸架与展开的壁纸库是同一集合的连续视图。快速选择用壁纸架，
搜索、筛选与大网格用**壁纸库**。打开壁纸详情可查看内容、按显示器名称应用，
也可把预览拖到显示器上。

封面用于预览，不是另一套实时壁纸渲染。实际播放以桌面和显示器状态为准；
选中了封面，不代表新来源已加载成功。

## 选择页面

| 页面 | 用途 |
|---|---|
| 全景 | 查看显示器排列、播放状态与已指定壁纸 |
| 壁纸库 | 浏览当前版本支持的导入/保存内容、Apple 航拍与已安装创意工坊内容 |
| 方案 | 保存、恢复一台显示器的整套配置 |
| 创意工坊——Pro | 浏览线上条目、喜欢后留待下载、下载并查看社区预设 |
| 系统壁纸——macOS 26+ | 发布支持的视频，供 macOS 壁纸设置选择 |
| 设置 | 调整应用默认值、性能规则、系统联动与维护选项 |

**系统壁纸**使用独立的视频 provider；发布状态与 Loomscreen 内正在运行的壁纸、
macOS 当前选中的壁纸是不同的状态。

## 编辑壁纸播放

显示器编辑器的**壁纸**页提供播放控制与来源检查器。适配、静音/音量与帧率上限
属于当前显示器；菜单栏总开关控制所有壁纸。

视频有速度和调色，网页有来源、JavaScript、网络与布局选项，Pro 场景有作者属性和场景预设。
帧率控件配置上限，不是实际 FPS 测量表。

普通属性边改边保存。**壁纸自动切换**为播放列表、每日计划与壁纸库随机打开草稿编辑器；
**保存**提交草稿，**取消**还会恢复试播前的配置。见[快速上手](quick-start.md#4播放列表与轮换)。

## 排列叠加层

切到显示器编辑器的**叠加层**，在同一画布上排列小组件、时钟与音乐。
通过图层列表选择对象，在对象检查器里调整。**添加小组件**打开添加面板：
点击可放到空闲位置，拖入画布可指定位置。面板包含十一种小组件，另有独立音乐与时钟层。

在预览里移动、调整大小。**示例数据**帮助检查布局，不代表当前读数。
粒子与天气联动使用效果层设置；共用编辑器不会改变各运行窗口的独立所有权。

开启小组件交互后，只有可见小组件区域接收桌面点击，空白区域仍可穿透。
时钟和音乐控制保留各自的交互行为。

## 书签、喜欢、预设与方案

| 项目 | 保存什么 |
|---|---|
| 黄色书签 | 已有壁纸库条目的标记，用书签筛选查找 |
| 粉色创意工坊喜欢——Pro | 留待稍后下载的线上条目；不会下载、订阅或应用 |
| 场景预设——Pro | 某个基础场景的一组命名参数 |
| 整屏方案 | 一台显示器的壁纸、叠加层与自动化等整套配置 |

取消书签或喜欢只移除标记，不删除壁纸媒体。方案与 `.lwconfig` 备份引用本地文件，
不打包媒体、凭据或可跨机器使用的文件授权。

## 设置与说明

设置侧栏按配置、播放、内容、数据、支持分组，搜索可定位匹配设置。
每屏壁纸编辑在显示器编辑器中完成；**显示器默认值**定义显示器配置的默认参数。

浮动的**欢迎导览**高亮实际控件，用关闭按钮或 Esc 退出后即可操作页面。
**设置 → 关于 → 欢迎导览**可重开，**了解此页面**按钮提供当前页指引。
权限与恢复方法见[安装说明](install.md)和[故障排查](troubleshooting.md)。
