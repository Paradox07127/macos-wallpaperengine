# 快速上手

[English](../en/quick-start.md) · **简体中文**

从零到第一张壁纸，再到你日常真正会用的功能。安装步骤见
[install.md](install.md)；完整的功能 ↔ 代码对照见 [features.md](features.md)。

## 1）首次启动

[安装](install.md)完成后启动 Loomscreen，会打开引导流程：

- **导入文件** → 视频（`mp4`/`m4v`/`mov`/`avi`）、网页（`.html` 文件或文件夹），Pro 版还可以选 Wallpaper Engine 场景文件夹。
- **Apple Aerials** → 从 Mac 上已下载的航拍视频里挑。
- 多显示器时，可以只应用到一台，也可以选**所有显示器**。

跳过引导也没关系——下面所有事情都能在设置窗口里做。

## 2）先认识两个界面

- **菜单栏图标** —— 日常操作：添加壁纸、总开关、每台显示器的播放/暂停与上一张/下一张、音量、CPU/GPU/内存/温度实时条、重新加载、退出。
- **设置窗口**（菜单栏 → **管理**）—— 侧栏列出你的**显示器**，以及**已保存**（壁纸与方案）、**Apple Aerials**、（Pro）**Steam 创意工坊**和 macOS 26+ 的**系统壁纸**；通用、显示器默认值、性能、天气、快捷键、备份等设置页也在同一个窗口里。

## 3）把一台显示器配完整

1. **设置 → 显示器** → 选一台显示器。
2. 选壁纸类型：**视频 / 网页 / 场景**（场景是 Pro 独有；Lite 只显示它能渲染的类型）。
3. 在预览区选来源——文件选择器，或者直接把文件拖到显示器那一行。
4. 在检查器里调：
   - **壁纸**页 —— 音量/静音、帧率目标（15/30/60/跟随显示器，标签显示实际帧率）、适配模式、视频色彩空间（含 HDR）、播放速度；网页壁纸另有 JavaScript 开关、跟踪器拦截、自定义 CSS 与自动刷新；场景另有光标视差、点击交互和一行**预设**。
   - **叠加层**页 —— 选择**天气**、**组件**或**音乐**。可配置 12 种粒子与天气联动、排列含天气在内的十种组件，或开启独立音乐层。每类有自己的预览，可拖动定位组件和音乐层。
5. 改动即时生效并保存，没有单独的保存步骤。

## 4）播放列表与轮换

在显示器的**播放列表**区块：

- 添加视频、拖拽排序、删除条目。
- 设置轮换间隔（1–1440 分钟），开关随机播放。
- 应用到当前显示器或所有显示器。

对于正在跑播放列表的显示器，菜单栏里也会出现上一张/下一张。

## 5）时段计划

在**计划**区块里，用预设时段（早晨、正午、下午、傍晚、夜间）或自定义时间范围添加时段，
再给每个时段挂一个书签。时段重叠会被标出来。没有任何时段命中时，显示器回到它的主壁纸。
你离开时（锁屏、显示器休眠）自动化会整个停下，唤醒后只对齐一次——错过的时段不会补触发。

## 6）已保存壁纸与方案

在显示器标题栏保存壁纸后，可从**已保存 → 书签**找到它。书签只切换内容，保留目标显示器设置。
要保存包含播放、叠加层、播放列表与计划的整屏配置，使用**已保存 → 方案**；应用方案会在确认后
替换目标显示器的配置。方案引用本地文件，换一台 Mac 后可能需要重新选择来源。

## 7）全局快捷键

**设置 → 快捷键** —— 一个总开关加八个可绑定的动作：全部播放/暂停、下一张/上一张壁纸
（光标所在的显示器）、切换静音、切换鼠标交互、显示/隐藏所有壁纸、重新加载所有壁纸、
打开设置窗口。

## 8）创意工坊配置（Pro）

Steam 创意工坊页需要做一次性配置，应用内有引导：

1. 打开 **设置 → 创意工坊**。页面顶部的状态条会显示三项前置条件各自的进度，下面的 **Steam 连接**那一节逐条列出它们，并提供自动配置。
2. **SteamCMD** —— 下载走 Valve 的命令行工具，用你自己的 Steam 账号；有缓存登录的账号会被自动发现并列出。拿到这个工具有三条路，都在 **SteamCMD** 那一行上——按钮是当前状态下最常用的那个，其余收在旁边的 `⋯` 菜单里：
   - **安装 SteamCMD…** —— 由 Loomscreen 装一份托管副本。它会拉取 Valve 的包清单，把每个下载文件与清单里的 SHA-256 对校，解包，只有当二进制的代码签名与团队标识确实是 Valve 的才保留结果。任何一步失败都会回滚，不动你原来的配置。
   - **自动查找** —— 找出已有的安装（Homebrew、`/usr/local/bin` 之类）。
   - **选择 SteamCMD…** —— 自己指定一个二进制。它照样要过同样的签名与校验和门禁，而且是**每次运行**都过，不只是你选它的那一次。
3. **Steam Web API key** —— 用于 API 浏览、作者资料和预设列表；公共浏览与按链接下载可在没有 key 时使用。在 [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) 申请。新 key 保存到登录钥匙串；旧文件 key 在钥匙串访问成功后迁移。
4. **引擎资源** —— 场景会引用 Wallpaper Engine 的共享资源；Loomscreen 通过 SteamCMD 一次性下载，并可在启动时检查更新（**设置 → 创意工坊**）。

按引导登录 Steam 账号，支持 Steam Guard。下载进入授权的 Steam 库，订阅同步让已订阅内容
出现在应用里。也可链接本地项目文件夹，就地读取资源。标签/作者页面仍保留其他浏览筛选条件。

## 9）场景预设（Pro）

创意工坊里每张壁纸的页面还会列出社区发布的**预设**——一个预设就是那张壁纸自身设置的一份存档，
外加作者选定的色彩校正与音量。下载一个之后，它会出现在场景设置卡片的**预设**那一行。

**设置 → 创意工坊 → 把预设当作壁纸显示**默认关闭；开启后，通用浏览网格才会包含预设。
基础壁纸的详情页仍提供预设列表。

这一行把*你保存的*和*来自创意工坊*的分开列，菜单里提供**将当前参数保存为预设…**、**重命名…**
和**删除预设**。预设是叠在场景默认值之上的一层，而你自己的改动又是叠在预设之上的一层——
所以之后你改的东西始终归你，删掉预设也不会带走你的改动。

## 10）音乐、天气与系统播放

- **叠加层 → 音乐**：开启音乐层，选择 Poster/Vinyl/Aurora，在预览里拖拽定位，并选择是否显示控制与歌词。歌词默认关闭；Spotify/Music 自动化权限用于控制与缺失播放位置的读取，Pro 音频响应用于动态视觉效果。
- **叠加层 → 组件**：在 CPU、内存等组件旁添加天气；位置来源在**设置 → 天气**选择系统或手动。
- **系统壁纸**（macOS 26+）：添加支持的视频，再打开 macOS 壁纸设置选择它。系统 provider 可在 Loomscreen 关闭后继续播放；这条路径不含场景、网页或叠加层，并受 provider 兼容性检查限制。

## 11）用过一天之后

- 回头看看 **设置 → 性能**：暂停规则（全屏、电池、低电量模式、遮挡）、按 App 的例外——包括给那些必须一直保持壁纸运行的 App 设**从不暂停**——以及视频的内存预载预算。
- 从 **设置 → 备份与恢复** 导出 `.lwconfig`，保存设置与引用，不携带媒体文件或密钥。Lite 不能播放 Pro 备份里的场景。
- 碰到边角情况？**设置 → 关于 → 报告问题…** 会自动填好诊断信息。
