# 快速上手

[English](../en/quick-start.md) · **简体中文**

从零到第一张壁纸，再到你日常真正会用的功能。安装步骤见
[install.md](install.md)；完整的功能 ↔ 代码对照见 [features.md](features.md)。

## 1）首次启动

[安装](install.md)完成后启动 Loomscreen，会打开引导流程：

- **导入文件** → 视频（`mp4`/`m4v`/`mov`/`avi`）、网页（`.html` 文件或文件夹），Pro 版还可以选 Wallpaper Engine 场景文件夹。
- **Apple 航拍** → 从 Mac 上已下载的航拍视频里挑。
- 多显示器时，可以只应用到一台，也可以选**所有显示器**。

跳过引导也没关系——下面所有事情都能在设置窗口里做。

## 2）先认识两个界面

- **菜单栏图标** —— 日常操作：添加壁纸、总开关、每台显示器的播放/暂停与上一张/下一张、音量、CPU/GPU/内存/温度实时条、重新加载、退出。
- **管理窗口**（菜单栏 → **管理**）—— 顶部导航包含**全景**、**壁纸库**、**方案**、**系统壁纸**、（Pro）**创意工坊**和**设置**。全景里点选显示器即可编辑；设置页另有自己的侧栏，包含通用、显示器默认值、性能、系统联动、快捷键、备份等页面。

## 3）把一台显示器配完整

1. 打开**全景**，点选要编辑的显示器。
2. 使用**更换壁纸**，或在**壁纸库**选中内容后应用到指定名称的显示器；场景壁纸需要 Pro。
3. **壁纸**页的预览控制条提供适配、音频和帧率；右侧检查器显示当前类型的其他选项。视频有速度和调色，网页有 JavaScript、跟踪保护、CSS 与刷新，场景有作者提供的自定义属性和预设。
4. 帧率可输入不高于该屏当前刷新率的整数，或选**最高**；可用预设包含 15/24/30/45/60/120。所选数值是上限，不是实际帧率测量。
5. **叠加层**是一块统一画布，配有图层列表、对象检查器和添加面板。添加小组件、时钟或音乐，再选择和定位；效果层提供粒子与天气联动。**示例数据**用于预览布局，不代表实时性能读数。

   开启小组件交互后，只有可见小组件区域接收点击，空白桌面仍可穿透。在叠加层编辑器中仍可正常选择和移动对象。

6. 普通属性边改边保存。**播放列表与计划**使用独立草稿，需点**保存**或**取消**。

## 4）播放列表与轮换

从显示器工具栏或检查器打开**播放列表与计划**：

- 从壁纸库添加当前版本支持的视频、网页、场景，可混合排列。
- 每行的箭头用于排序，播放按钮用于在当前显示器试播，移除按钮仅从队列移除条目。
- 轮播可选**手动**或 1、5、15、30、60、120 分钟，可开启**随机播放**。
- **保存**提交草稿；**取消**丢弃草稿并恢复试播前的配置。

正在使用播放列表的显示器，也可从菜单栏切上一张或下一张。

## 5）时段计划

在同一个编辑器切到**每日计划**，为各时间段指定壁纸；时段可跨午夜，重叠会显示错误并禁止保存。
**保存并使用每日计划**会把该显示器切换到计划模式。为没有时段覆盖的时间指定回退壁纸。
锁屏或显示器休眠期间暂停自动化，唤醒后对齐当前时段，不补播错过的时段。

## 6）书签与方案

在壁纸的菜单或详情中用黄色书签标记常用的壁纸，再在**壁纸库**选**书签**筛选，即可只看这些。
要保存包含播放、叠加层、播放列表与计划的整屏配置，使用**方案**页；应用方案会在确认后
替换目标显示器的配置。方案引用本地文件，换一台 Mac 后可能需要重新选择来源。

## 7）全局快捷键

**设置 → 快捷键** —— 一个总开关加八个可绑定的动作：全部播放/暂停、下一张/上一张壁纸
（光标所在的显示器）、切换静音、切换鼠标交互、显示/隐藏所有壁纸、重新加载所有壁纸、
打开设置窗口。

## 8）创意工坊配置（Pro）

先打开**创意工坊**搜索、筛选、排序和查看公开壁纸；公开浏览不需要 SteamCMD、登录或 API key。已安装条目可以直接应用到指定显示器。需要下载时，再按应用内引导完成配置：

1. 打开 **设置 → 创意工坊**。页面顶部的状态条会显示三项前置条件各自的进度，下面的 **Steam 连接**那一节逐条列出它们，并提供自动配置。
2. **SteamCMD** —— 下载走 Valve 的命令行工具，用你自己的 Steam 账号；有缓存登录的账号会被自动发现并列出。工具尚未就绪时，**SteamCMD** 那一行提供**设置 SteamCMD**、**自动查找**和**选择 SteamCMD**；就绪后换成**更改**、**自动查找**和**设置 SteamCMD**：
   - **设置 SteamCMD** —— 打开一个弹窗，有两种方式可选。**通过 Loomscreen 安装**会列出下载大小和安装位置，点击**下载并安装**后由 Loomscreen 装一份托管副本。它会拉取 Valve 的包清单，把每个下载文件与清单里的 SHA-256 对校，解包，只有当二进制的代码签名与团队标识确实是 Valve 的才保留结果。任何一步失败都会回滚，不动你原来的配置。**用 Homebrew 安装**会给出一条终端命令和**复制**按钮；在终端运行后，再点击**自动查找**。
   - **自动查找** —— 找出已有的安装（Homebrew、`/usr/local/bin` 之类）。
   - **选择 SteamCMD**（就绪后是**更改**）—— 自己指定一个二进制。它照样要过同样的签名与校验和门禁，而且是**每次运行**都过，不只是你选它的那一次。
   - 按钮旁的 `⋯` 菜单只在有可撤回的操作时出现：**忘记我选择的 SteamCMD** 会回到自动查找；**删除 Loomscreen 安装的那份**会在你确认后删除托管副本。
3. **Steam Web API key** —— 用于 API 浏览、作者资料和预设列表；公共浏览与按链接下载可在没有 key 时使用。在 [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) 申请。新 key 保存到登录钥匙串；旧文件 key 在钥匙串访问成功后迁移。
4. **引擎资源** —— 场景会引用 Wallpaper Engine 的共享资源；Loomscreen 通过 SteamCMD 一次性下载，并可在启动时检查更新（**设置 → 创意工坊**）。

按引导登录 Steam 账号，支持 Steam Guard。下载进入授权的 Steam 库，订阅同步让已订阅内容
出现在应用里。也可链接本地项目文件夹，就地读取资源。标签/作者页面仍保留其他浏览筛选条件。

## 9）场景预设（Pro）

创意工坊里每张壁纸的页面还会列出社区发布的**预设**——一个预设就是那张壁纸自身设置的一份存档，
外加作者选定的色彩校正与音量。下载一个之后，它会出现在场景设置卡片的**预设**那一行。

**设置 → 创意工坊 → 把预设当作壁纸显示**默认关闭；开启后，通用浏览网格才会包含预设。
基础壁纸的详情页仍提供预设列表。

这一行把*你保存的*和*来自创意工坊*的分开列，菜单里提供**另存为新预设**、**重命名**
和**删除预设**。如果当前应用的是你自己保存的预设，并且之后又改过参数，菜单里还会出现**更新“*名称*”**，
用来把这些改动存回该预设。预设是叠在场景默认值之上的一层，而你自己的改动又是叠在预设之上的一层——
所以之后你改的东西始终归你，删掉预设也不会带走你的改动。

## 10）音乐、天气与系统播放

- **叠加层**：从添加面板或图层列表选中音乐，开启音乐层，选择 Poster/Vinyl/Aurora，在预览里拖拽定位，并选择是否显示控制与歌词。歌词默认关闭；Spotify/Music 自动化权限用于控制与缺失播放位置的读取，Pro 音频响应用于动态视觉效果。
- **叠加层**：从添加面板添加天气，与 CPU、内存等小组件一起排列；位置来源在**设置 → 系统联动 → 天气**选择系统或手动。
- **系统壁纸**（macOS 26+）：添加支持的视频，再打开 macOS 壁纸设置选择它。系统 provider 可在 Loomscreen 关闭后继续播放；这条路径不含场景、网页或叠加层，并受 provider 兼容性检查限制。

## 11）用过一天之后

- 回头看看 **设置 → 性能**：暂停规则（全屏、电池、低电量模式、遮挡）、按 App 的例外——包括给那些必须一直保持壁纸运行的 App 设**从不暂停**——以及视频的内存预载预算。
- 从 **设置 → 备份与恢复** 导出 `.lwconfig`，保存设置与引用，不携带媒体文件或密钥。Lite 不能播放 Pro 备份里的场景。
- 碰到边角情况？**设置 → 关于 → 报告问题** 会自动填好诊断信息。

在管理窗口内切换页面（包括设置和壁纸库）后，创意工坊会保留搜索、筛选、页码和选中项目。此浏览状态在管理窗口销毁时结束，不会跨应用重启保存。

## 先喜欢创意工坊壁纸

在创意工坊卡片、右键菜单或详情中点粉色心形，即可在下载前喜欢一张壁纸。打开创意工坊筛选栏里的**已喜欢**开关，就能看到喜欢过的壁纸，打开详情并稍后下载。喜欢仅保存到本机，不会下载、订阅或应用壁纸。Pro 的 .lwconfig 导出包含你的喜欢，但不打包下载的壁纸媒体。
