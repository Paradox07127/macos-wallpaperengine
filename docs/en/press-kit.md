# Loomscreen Copy Kit

**English** · [简体中文](../zh-Hans/press-kit.md)

Reusable copy for the project homepage, social posts and demos. These describe
the current workspace; release notes should describe changes in that release
and follow [Releasing](releasing.md).

## Main line

**A living desktop, arranged your way.**

Native macOS live wallpapers, a visual workspace for every display, and
widgets, music and weather in one overlay canvas.

## One sentence

Loomscreen is a free, open-source macOS live wallpaper app that brings your
displays, wallpapers and desktop overlays into one visual workspace.

## Short description

See every display, drag a wallpaper into place, and arrange widgets, clock and
music on one canvas. Loomscreen plays video, web and Apple Aerials wallpapers;
Pro adds an independent Metal renderer for Wallpaper Engine scenes and Steam
Workshop. Save display schemes, automate wallpaper changes and keep everyday
controls in the menu bar. Both editions are free and MIT licensed, with no
Loomscreen account or usage telemetry.

## UI announcement

**Meet your new desktop workspace.**

The redesigned Loomscreen starts with your displays. Overview, the wallpaper
shelf and the full library flow together; the display editor brings playback
and a shared overlay canvas close to the desktop you're changing. Choose a
wallpaper, place your widgets and save the setup for later.

## Feature captions

- **Every display, in view.** See where each wallpaper belongs.
- **From library to desktop.** Drag a wallpaper onto a display or apply it by name.
- **One canvas for your layers.** Arrange widgets, clock and music together.
- **A desktop that changes with your day.** Use playlists, schedules or library shuffle.
- **Wallpaper Engine scenes on Mac.** Pro renders compatible scenes natively with Metal.
- **Your files, your setup.** No Loomscreen account or usage telemetry.

## Claim boundaries

| Topic | Accurate wording |
|---|---|
| Editions | Lite and Pro are both free and open source; Pro adds the WPE/Workshop stack and related capabilities |
| WPE | Independent implementation; compatibility varies by project; no promise of complete Windows parity |
| Workshop | Downloads use the user's Steam account and license; no bundled content or entitlement bypass |
| Privacy | No Loomscreen account or usage telemetry; optional online features contact their own services |
| Performance | Power-aware rules and configurable frame-rate ceilings; efficiency claims require measured evidence |
| Intel | Lite ships an Intel slice that remains untested on Intel hardware; Pro requires Apple Silicon |
| System Wallpaper | macOS 26+, video only, subject to provider compatibility; excludes app scenes, web and overlays |
